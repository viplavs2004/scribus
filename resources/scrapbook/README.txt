Bundled scrapbook libraries
===========================

Ad Shapes      - starter set of editable vector elements for advertising layouts (offer bursts, sale
                 seals, price tags, ribbons, speech bubble, arrow, ratings, border strip, corner,
                 divider, swooshes, festive ornaments, phone/chat badges), a few colour variants each.
                 One folder per category; every element is a group with editable text frames.
Ad Shapes SVG  - the same artwork as plain SVG files (text is outlined when imported).

Open in Scribus:  Windows > Scrapbook.  "Ad Shapes" is opened automatically as its own tab;
otherwise click "Create a new scrapbook page" (first button in the palette) and choose
<share>/scrapbook/Ad Shapes.  Double-click an element to paste it onto the current page, or drag it.

Colours are named print colours (CMYK, prefix "Ad "). All artwork is original (drawn with code from
geometric primitives); no third-party artwork. Fonts: Arial / Arial Black (Windows system fonts).
